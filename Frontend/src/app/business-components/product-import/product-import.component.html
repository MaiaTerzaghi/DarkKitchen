Información

¿Cómo funciona?

El sistema carga dinámicamente plugins desde la carpeta /Plugins usando reflection. Cada plugin implementa la interfaz IProductImporter.

Extensibilidad

Puedes agregar nuevos importadores sin recompilar la aplicación. Solo coloca el DLL en /Plugins y se cargará automáticamente.

Formato esperado

Cada plugin define su propio formato de datos. Consulta la documentación de cada importador para conocer la estructura esperada.
